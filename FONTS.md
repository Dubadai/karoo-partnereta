# Fonts

`app/src/main/res/font/plex_*.ttf` are IBM Plex Sans (Medium, SemiBold, and the variable one, plex_var), the Karoo's own system
font, by IBM, under the SIL Open Font License 1.1: https://github.com/IBM/plex/blob/master/LICENSE.txt
The field's clock uses them, so it looks the same on every Karoo and in the field gallery.
